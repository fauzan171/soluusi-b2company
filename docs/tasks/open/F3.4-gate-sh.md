# F3.4 — scripts/gate.sh

## Goal
Pre-merge gate: lint, test, no secret.

## Perubahan

Buat `scripts/gate.sh`:

```bash
#!/bin/bash
set -e

echo "=== Gate check ==="

# 1. PHP syntax check
echo "1. PHP syntax..."
find app -name "*.php" -exec php -l {} \; > /dev/null

# 2. Composer validate
echo "2. Composer validate..."
composer validate --no-check-all

# 3. Test
echo "3. Tests..."
php artisan test --stop-on-failure

# 4. No secrets in code
echo "4. Secret scan..."
if grep -rn "APP_KEY\|password\|secret\|token" app/ --include="*.php" | grep -v "config/" | grep -v "database/" | grep -v "Hash::make" | grep -v "bcrypt"; then
    echo "WARNING: Potential secrets found"
    exit 1
fi

# 5. No debug code
echo "5. Debug code scan..."
if grep -rn "dd(\|dump(\|var_dump(" app/ --include="*.php"; then
    echo "WARNING: Debug code found"
    exit 1
fi

echo "=== Gate PASSED ==="
```

## Verify
- [ ] `bash scripts/gate.sh` executable
- [ ] Fail jika ada secret/test fail
- [ ] Pass jika semua bersih
