# T7.3 — Fix HR active sessions overnight filter

## Goal
Sessions running past midnight should still appear in HR "Sesi aktif" view.

## Evidence
`Perusahaan\DashboardController.php:31` — filter `scheduled_at >= today 00:00` misses overnight sessions.

## Perubahan
Change filter from:
```php
->where('scheduled_at', '>=', now()->startOfDay())
```
To:
```php
->where(fn ($q) => $q->where('status', 'in_progress')
    ->orWhere(fn ($q2) => $q2->where('status', 'scheduled')
        ->where('scheduled_at', '>=', now()->subHours(12))))
```

Or simpler: use `status = 'in_progress'` if that status exists, otherwise use time-based window.

- [ ] Test: session at 23:00 still visible at 01:00 next day
- [ ] HR dashboard shows correct active sessions
