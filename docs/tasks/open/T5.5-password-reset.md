# T5.5 — Implement password reset flow

## Goal
Standard Laravel password reset: request link → email → reset form → new password.

## Perubahan
1. Add routes:
   - `GET /forgot-password` → show request form
   - `POST /forgot-password` → send reset link
   - `GET /reset-password/{token}` → show reset form
   - `POST /reset-password` → update password

2. Create views:
   - `resources/views/auth/forgot-password.blade.php`
   - `resources/views/auth/reset-password.blade.php`

3. Use Laravel's built-in `Password` facade:
   - `Password::sendResetLink($request->only('email'))`
   - `Password::reset($credentials, function ($user, $password) { ... })`

4. Add "Lupa password?" link on login page

5. Configure mail for local dev (log driver or mailhog)

## Verify
- [ ] Manual flow: request reset → receive email → click link → set new password → login
- [ ] `php artisan test --filter=PasswordResetTest` passes

## Out of scope
- Custom email template design
