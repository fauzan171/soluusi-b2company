# T2.2 — Policies for session ownership

## Goal
Replace inline `abort_unless` ownership checks with proper Laravel Policies.

## Evidence
- `ChatController.php` — 5× `abort_unless($employee && $session->employee_id === $employee->id, 403)` and similar for consultant
- `Klinik\SessionController.php:98-102` — hand-rolled `authorizeConsultant`

## Perubahan
1. Create `app/Policies/PerusahaanSessionPolicy.php`:
   - `view(User $user, PerusahaanSession $session)` — employee owns session OR consultant assigned
   - `send(User $user, PerusahaanSession $session)` — same as view + session is active
   - `end(User $user, PerusahaanSession $session)` — employee or consultant owns it
   - `rate(User $user, PerusahaanSession $session)` — employee owns it + status done

2. Create `app/Policies/ConsultationSessionPolicy.php`:
   - `checkIn(User $user, ConsultationSession $session)` — consultant owns it
   - `markDone(User $user, ConsultationSession $session)` — consultant owns it
   - `verify(User $user, ConsultationSession $session)` — admin role

3. Register policies in `app/Providers/AuthServiceProvider.php` (or `AppServiceProvider` if Laravel 11+ style).

4. Refactor `ChatController`:
   - Replace `abort_unless($employee && ...)` with `$this->authorize('view', $session)` etc.
   - Remove duplicate ownership resolution

5. Refactor `Klinik\SessionController`:
   - Replace `authorizeConsultant()` calls with `$this->authorize('checkIn', $session)` etc.
