# T1.4 — Gate dummy payment routes by APP_ENV

## Goal
Dummy payment routes membiarkan siapa saja "bayar" tanpa uang nyata. Harus 404 di production.

## Evidence
- `routes/web.php:18-19` — `dummy-payment` + `dummy-payment/success` tidak gated.

## Perubahan
1. Buat middleware `App\Http\Middleware\NotProduction` yang `abort(404)` jika `app()->environment('production')`.
2. Daftarkan sebagai alias `notprod` di `bootstrap/app.php` `withMiddleware()` (atau `app/Http/Kernel.php` sampai T4.1 selesai — cek state saat implementasi).
3. Terapkan ke 2 route dummy payment.

## Verify
- [ ] Test: dengan `APP_ENV=production php artisan config:cache`, GET `/checkout/{token}/dummy-payment` → 404.
- [ ] Test: dengan `APP_ENV=local`, route tetap 200.
- [ ] `php artisan test --filter=DummyPaymentGateTest` hijau.

## Out of scope
- Hapus dummy payment — masih dipakai demo lokal.
