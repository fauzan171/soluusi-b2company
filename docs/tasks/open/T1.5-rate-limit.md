# T1.5 — Rate limit chat send, booking, reschedule

## Goal
Tutup spam/abuse surface di endpoint yang dipanggil dari UI berulang.

## Perubahan
Tambah throttle middleware ke:
- `POST /employee/sessions/{session}/chat` (ChatController::employeeStore) → `throttle:60,1`
- `POST /consultant/sessions/{session}/chat` (ChatController::consultantStore) → `throttle:60,1`
- `POST /employee/booking` → `throttle:10,1`
- `POST /employee/request-consultation` → `throttle:10,1`
- `POST /employee/sessions/{session}/cancel` → `throttle:10,1`
- `POST /employee/sessions/{session}/reschedule` → `throttle:10,1`
- `POST /siswa/booking` → `throttle:10,1`
- `POST /siswa/sessions/{session}/cancel` + `/reschedule` → `throttle:10,1`

## Verify
- [ ] `grep -c "throttle" routes/web.php` ≥ 8.
- [ ] Test `RateLimitTest`: hit ke-11 pada booking → response 429.

## Out of scope
- Custom throttle by user (bukan IP) — deferred.
