# F2.1 — Consultant assignment management (superadmin)

## Goal
Superadmin assign/remove consultant dari perusahaan/klinik pool.

## Current State
- `ConsultantPool` model ada tapi tidak ada UI untuk manage
- Assignment implicit via `ConsultantPool::poolFor`

## Perubahan

1. Buat `app/Http/Controllers/Admin\ConsultantAssignmentController.php`:
   - `index` — list consultants dengan assignment status
   - `assign` — assign consultant ke perusahaan/klinik
   - `remove` — remove dari pool

2. Update `ConsultantPool` model:
   - Explicit assignment via junction table `consultant_pool_assignments`
   - Kolom: `consultant_id`, `tenant_type` (perusahaan/klinik/sekolah), `tenant_id`, `assigned_by`, `assigned_at`

3. View: `resources/views/admin/consultant-assignment.blade.php`

## Verify
- [ ] Test: superadmin assign consultant ke perusahaan
- [ ] Test: consultant muncul di pool perusahaan
- [ ] Test: remove dari pool
- [ ] Test: non-admin tidak bisa assign (403)

## Out of scope
- Bulk assignment
- Assignment history UI
