# F1.2 — Consultant slot proposal

## Goal
Consultant propose 2-3 slot options untuk request yang sudah di-ACC HR.

## Current State
- Request di-ACC → auto-assign consultant → consultant set 1 slot via dropdown
- Tidak ada mekanisme propose multiple slots

## Perubahan

1. Tambah table `session_slot_proposals`:
   - `id`, `session_id`, `consultant_id`, `proposed_at`, `slots` (JSON array of `{start, end}`), `status` (pending/accepted/rejected), `created_at`, `updated_at`

2. Update flow:
   - HR approve → status `scheduled`, `scheduled_at = null`
   - Consultant buka session → form propose slots (2-3 datetime options)
   - Submit → create `session_slot_proposals` record
   - Employee/HR lihat proposals → pilih 1 → session di-book

3. Buat `app/Http/Controllers/Consultant\SlotProposalController.php`:
   - `create` — form propose slots
   - `store` — save proposals

4. Update `ChatController::consultant` atau buat view baru untuk slot proposal.

5. Validasi: slots harus future, tidak overlap dengan existing bookings, max 3 slots.

## Verify
- [ ] Test: consultant bisa propose 2-3 slots
- [ ] Test: proposal tersimpan dengan status pending
- [ ] Test: slot overlap ditolak
- [ ] Test: max 3 slots enforced
- [ ] Manual browser: consultant propose flow

## Out of scope
- Calendar integration
- Recurring slots
