# T2.1 — Explicit $fillable on money/PII models

## Goal
Replace loose `$guarded` with explicit `$fillable` on all models that hold money, PII, or session state.

## Evidence
- `$guarded = []`: `Payment.php:12`, `SocialAccount.php:13`, `ConsultantCompany.php:12`
- `$guarded = ['id']`: `ConsultationSession.php:26`, `ChatMessage.php:9`, `ConsultantRating.php:12`, `ConsultantPool.php:17`, `Lead.php:11`, all Klinik/Perusahaan/Sekolah models

## Perubahan
For each model below, replace `$guarded` with explicit `$fillable` listing ONLY fields that should be mass-assignable:

**Critical (money/PII):**
- `app/Models/Payment.php`
- `app/Models/SocialAccount.php`
- `app/Models/ConsultantCompany.php`
- `app/Models/ConsultationSession.php`
- `app/Models/ChatMessage.php`
- `app/Models/ConsultantRating.php`
- `app/Models/ConsultantPool.php`

**Klinik family:**
- `app/Models/Klinik/*.php` (all 8 models)

**Perusahaan family:**
- `app/Models/Perusahaan/*.php` (all 5 models)

**Sekolah family:**
- `app/Models/Sekolah/*.php` (all 5 models)

**Other:**
- `app/Models/Lead.php`

## Verify
- [ ] `grep -rn "guarded = \[\]" app/Models` exit 1 (empty)
