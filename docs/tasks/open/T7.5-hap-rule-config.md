# T7.5 — Move HAP "Rule demo" to config

## Goal
Remove hardcoded demo rules from associate dashboard.

## Evidence
`resources/views/associate/dashboard.blade.php:20-22` — hardcoded "Stage 1 di 5 sesi, Stage 2 di 25 sesi, Stage 3 di 40 sesi"

## Perubahan
1. Add to `config/hap.php`:
```php
return [
    'pervorma_stages' => [
        1 => 5,
        2 => 25,
        3 => 40,
    ],
];
```

2. Update view to read from config:
```blade
@foreach(config('hap.pervorma_stages') as $stage => $sessions)
    Stage {{ $stage }} di {{ $sessions }} sesi{{ !$loop->last ? ',' : '' }}
@endforeach
```

## Verify
- [ ] `grep "Rule demo" resources/views/associate/dashboard.blade.php` empty
- [ ] View renders from config
