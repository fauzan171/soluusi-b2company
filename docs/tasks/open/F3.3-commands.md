Slash commands untuk workflow mandor/kuli.

## Perubahan

```markdown
# /mandor

Lead mode: eksplorasi, keputusan arsitektur, ADR, task spec, integrasi, review.

Usage: /mandor <task>
```

### dispatch.md
```markdown
# /dispatch

Dispatch kuli untuk task tertentu.

Usage: /dispatch <task-id> [worktree]
```

### review.md
```markdown

Usage: /review <task-id> [branch]
```

### ship.md
```markdown

Ship ke integration branch setelah QA pass.

Usage: /ship <task-id>
```

### docs-sync.md
```markdown
# /docs-sync

Sinkronisasi dokumentasi (PLAN.md, task.md, specs).

Usage: /docs-sync
```
