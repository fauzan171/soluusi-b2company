# T4.1 — Complete Laravel 11+ skeleton migration

## Goal
Finish the Laravel 12 upgrade by migrating from legacy Kernel files to `bootstrap/app.php`.

## Evidence
- `bootstrap/app.php` still binds `Http\Kernel` and `Console\Kernel` manually
- `app/Http/Kernel.php` has full `$middlewareGroups` and `$routeMiddleware`
- Laravel 11+ expects `withMiddleware()` in `bootstrap/app.php`

## Perubahan
1. Move middleware aliases from `app/Http/Kernel.php` `$routeMiddleware` to `bootstrap/app.php` `->withMiddleware()` call
2. Move middleware groups from `$middlewareGroups` to `withMiddleware()` web/api group calls
3. Move any global middleware from `$middleware` to `withMiddleware()`
4. Delete `app/Http/Kernel.php`
5. Move console commands/schedule from `app/Console/Kernel.php` to `routes/console.php` or `bootstrap/app.php`
6. Delete `app/Console/Kernel.php`

## Verify
- [ ] `ls app/Http/Kernel.php` fails (file doesn't exist)
- [ ] `ls app/Console/Kernel.php` fails
- [ ] `php artisan route:list` exit 0
- [ ] `php artisan test` — all tests pass
- [ ] `php artisan config:cache && php artisan route:cache` exit 0

## Out of scope
- Changing any middleware logic — only moving registration
