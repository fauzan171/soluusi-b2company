# F2.4 — Full flow integration test

## Goal
End-to-end test untuk flow lengkap: request → HR review → assignment → slot proposed → confirmed → in-session → completed.

## Perubahan

1. Buat `tests/Feature/FullFlowTest.php`:

```php
public function test_full_consultation_flow()
{
    // 1. Employee request consultation
    // 2. HR review and approve
    // 3. System assign consultant (or HR override)
    // 4. Consultant propose slots
    // 5. Employee confirm slot
    // 6. Session scheduled
    // 7. Consultant check-in (start)
    // 8. Chat exchange
    // 9. Consultant end session
    // 10. Employee rate
    // 11. Session completed
}
```

2. Test juga variant:
   - HR reject
   - Employee cancel
   - Reschedule
   - Auto-cancel (expired)

## Verify
- [ ] `php artisan test --filter=FullFlowTest` hijau
- [ ] Semua state transitions tercatat benar
- [ ] Quota ter-update dengan benar
- [ ] Audit log terisi (jika applicable)

## Out of scope
- Performance testing
- Load testing
