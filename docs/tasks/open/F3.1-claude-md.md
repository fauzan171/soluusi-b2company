# F3.1 — CLAUDE.md + AGENTS.md untuk workflow mandor/kuli

## Goal
Dokumentasi workflow mandor/kuli yang jelas untuk agent coding.

## Perubahan

1. Buat `CLAUDE.md` di repo root:

```markdown
# Soluusi B2B — Agent Coding Guide

## Roles
- **Mandor**: Lead, eksplorasi, keputusan arsitektur, ADR, task spec, integrasi, review.
- **Kuli**: Executor. Implementasi mekanis di worktree terisolasi.

## Model Routing
- Kuli: `tg/glm-5.3` (verified via CLI headless)
- Reviewer: `tg/glm-5.3` atau `sonnet`
- Mandor: `sonnet` atau `opus`

## Workflow
1. Mandor buat task spec di `docs/tasks/open/`
2. Kuli dispatch via `scripts/kuli.sh` atau CLI headless
3. Kuli kerja di worktree `soluusib2b-kuli-<task-id>`
4. Reviewer verifikasi hasil
5. Mandor integrasi ke `goal/production-foundation`

## Rules
- Jangan push tanpa QA
- Jangan deploy tanpa owner approval
- Jangan overwrite .env
- Jangan migrate:fresh/refresh/reset
```

2. Buat `AGENTS.md`:

```markdown
# Subagents

## auditor
- Read-only audit
- Output: AUDIT.md

## backend
- Laravel backend implementation
- Test: php artisan test

## frontend
- Blade/Alpine implementation
- Test: manual browser

## test
- Test writing
- Test: php artisan test

## docs
- Documentation
- Test: markdown lint

## reviewer
- Independent review
- Verify acceptance criteria

## server-ops
- Server read-only recon
- No mutation without approval
```
