# F2.2 — View-as middleware + audit

## Goal
Superadmin impersonasi tenant admin dengan audit logging.

## Current State
- `EmployeeController::resolveEmployee` support `?employee_id=` untuk superadmin
- Tidak ada audit log
- Tidak ada middleware khusus

## Perubahan

1. Buat middleware `App\Http\Middleware\ViewAs`:
   - Check user is superadmin
   - Log view-as action ke `admin_actions`
   - Set view-as context (tenant, target user)
   - Add header/banner "Viewing as X"

2. Update `resolveEmployee` dan sejenisnya:
   - Wajibkan `employee_id` eksplisit (tidak ada fallback)
   - Log setiap view-as access

3. Buat helper `app/Support/ViewAs.php`:
   - `start($user, $target)` — start view-as session
   - `stop()` — end view-as
   - `current()` — get current view-as context
   - `isActive()` — check if view-as active

4. View: banner "Anda sedang melihat sebagai [User]" dengan tombol stop.

## Verify
- [ ] Test: view-as logged ke `admin_actions`
- [ ] Test: view-as hanya untuk superadmin
- [ ] Test: data ter-scope ke tenant yang di-view-as
- [ ] Test: banner muncul saat view-as aktif
- [ ] Manual browser: view-as flow

## Out of scope
