# F3.5 — scripts/kuli.sh

## Goal
Kuli launcher dengan model routing tg/glm-5.3.

## Perubahan

Buat `scripts/kuli.sh`:

```bash
#!/bin/bash
set -e

TASK_ID=$1
WORKTREE=${2:-"soluusib2b-kuli-$TASK_ID"}
BRANCH=${3:-"kuli/$TASK_ID"}
MODEL="tg/glm-5.3"

if [ -z "$TASK_ID" ]; then
    echo "Usage: $0 <task-id> [worktree] [branch]"
    exit 1
fi

# Validate task spec exists
SPEC="docs/tasks/open/$TASK_ID.md"
if [ ! -f "$SPEC" ]; then
    echo "ERROR: Task spec not found: $SPEC"
    exit 1
fi

# Create worktree if not exists
if [ ! -d "../$WORKTREE" ]; then
    echo "Creating worktree: $WORKTREE"
    git worktree add "../$WORKTREE" -b "$BRANCH" main
fi

# Read spec
echo "Reading spec: $SPEC"
PROMPT=$(cat "$SPEC")

# Dispatch kuli
echo "Dispatching kuli with model: $MODEL"
cd "../$WORKTREE"

claude -p "You are kuli (executor). Implement this task:

$PROMPT

RULES:
- Read files first
- Minimal changes
- Run verify commands
- Report results" \
    --model "$MODEL" \
    --no-session-persistence \
    --output-format json

echo "=== Kuli dispatch complete ==="
```
