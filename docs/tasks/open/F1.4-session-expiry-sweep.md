# F1.4 — Session expiry sweep

## Goal
Auto-cancel scheduled sessions yang lewat tanpa check-in.

## Current State
- Tidak ada auto-cancel untuk sessions yang expired
- Session bisa stuck di `scheduled` selamanya

## Perubahan

1. Tambah config `config/session.php`:
```php
'auto_cancel_hours' => env('SESSION_AUTO_CANCEL_HOURS', 24),
```

2. Buat command `app/Console/Commands/CancelExpiredSessions.php`:
   - Cari sessions `status = scheduled`, `scheduled_at < now()->subHours(config('session.auto_cancel_hours'))`
   - Update status `cancelled`, `cancel_reason = 'Auto-cancelled: no check-in'`
   - Restore quota jika perlu

3. Register di `routes/console.php` atau `bootstrap/app.php` schedule:
```php
Schedule::command('sessions:cancel-expired')->hourly();
```

4. Update `SessionStateMachine` dengan method `autoCancel($session)`.

## Verify
- [ ] Test: session > 24 jam tanpa check-in → auto-cancelled
- [ ] Test: quota restored untuk auto-cancel
- [ ] Test: session < 24 jam tidak di-cancel
- [ ] Manual: `php artisan sessions:cancel-expired` jalan

## Out of scope
- Reminder sebelum auto-cancel
- Configurable per tenant
