# T2.3 — Cross-tenant isolation tests

## Goal
Prove tenant isolation works: users from company A cannot access company B's data.

## Perubahan
Create `tests/Feature/TenancyIsolationTest.php` with these scenarios:

**Perusahaan isolation:**
1. Employee A (perusahaan X) cannot GET `/perusahaan/employee` for employee B (perusahaan Y) — expect 403 or own data only
2. Employee A cannot POST to employee B's session chat — expect 403
3. HR admin A cannot access HR dashboard for perusahaan B — expect 403

**Consultant isolation:**
4. Consultant cannot access session assigned to different consultant — expect 403
5. Consultant cannot check-in to another consultant's session — expect 403

**Cross-vertical isolation:**
6. Employee (perusahaan) cannot access Sekolah student endpoints — expect 403
7. Klinik admin cannot access Perusahaan HR endpoints — expect 403

**Session isolation:**
8. Chat messages from session A not visible in session B
9. Rating for session A doesn't affect session B

## Verify
- [ ] `php artisan test --filter=TenancyIsolationTest` — all scenarios pass
- [ ] At least 6 negative test cases (403 responses)

## Out of scope
- Positive tests (already covered in existing tests)
