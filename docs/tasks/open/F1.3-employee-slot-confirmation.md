# F1.3 — Employee slot confirmation

## Goal
Employee pilih 1 slot dari proposal consultant, session ter-book otomatis.

## Current State
- Tidak ada slot confirmation flow
- Consultant langsung set `scheduled_at` via dropdown

## Perubahan

1. Update `EmployeeController` atau buat `SlotConfirmationController`:
   - `index` — list pending slot proposals untuk employee
   - `confirm` — pilih 1 slot, update session `scheduled_at`, reject other proposals

2. Update view employee dashboard:
   - Card "Pilih Jadwal" jika ada pending proposal
   - Radio/button untuk pilih slot
   - Submit → confirm

3. Update session status flow:
   - `scheduled` + `scheduled_at = null` → menunggu proposal
   - Proposal submitted → `scheduled` + `scheduled_at = null` + has proposals
   - Employee confirm → `scheduled` + `scheduled_at = chosen_slot`
   - Auto-reject other proposals

4. Notifikasi ke consultant bahwa slot dipilih.

- [ ] Test: employee tidak bisa confirm proposal orang lain (403)
- [ ] Manual browser: employee confirm flow

## Out of scope
- Reschedule setelah confirm (sudah ada di T6.2)
- Counter-proposal (employee propose balik)
