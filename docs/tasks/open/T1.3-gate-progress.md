# T1.3 — Gate /progress di belakang auth + role:admin

## Goal
Halaman `/progress` menampilkan metrik internal DB (employee count, sessions, students, users, question bank). Saat ini public — bocor.

## Evidence
- `routes/web.php:66-67` tidak ada middleware.
- `app/Http/Controllers/ProgressController.php` render data internal.

## Perubahan
1. Edit `routes/web.php:67` — tambahkan `->middleware(['auth', 'role:admin'])`.
2. Buat test `tests/Feature/ProgressGateTest.php`:
   - anonymous GET `/progress` → redirect `/login`.
   - employee login GET `/progress` → 403.
   - admin login GET `/progress` → 200.

## Verify
- [ ] `php artisan test --filter=ProgressGateTest` hijau.
- [ ] Manual browser: tanpa login, akses `/progress` → redirect ke `/login`.

## Out of scope
- Hapus halaman — itu opsi alternatif; tetap ada tapi gated untuk demo internal.
