# T6.1 — AI service seam with interface + feature flag

## Goal
AI integration behind interface, provider via env, feature flag per tenant. No active AI calls yet.

## Perubahan

1. Create `app/Contracts/AIService.php`:
```php
interface AIService
{
    public function generateInsight(array $payload): array;
}
```

2. Create `config/ai.php`:
```php
return [
    'provider' => env('AI_PROVIDER', 'null'),
    'providers' => [
        'null' => App\Services\AI\NullAIService::class,
        // 'openai' => App\Services\AI\OpenAIService::class, // future
    ],
];
```

3. Create `app/Services/AI/NullAIService.php` — returns empty/null insight

4. Add `ai_enabled` boolean to tenant tables:
   - Migration: add to `kliniks`, `perusahaans`, `sekolahs`
   - Default false

5. Refactor `AiInsightService` to:
   - Check `$tenant->ai_enabled` first
   - Resolve provider from `config('ai.provider')`
   - Call `$provider->generateInsight($payload)`

6. Bind in `AppServiceProvider`:
```php
$this->app->bind(AIService::class, fn () => new (config('ai.providers')[config('ai.provider')]));
```

## Verify
- [ ] `interface_exists(App\Contracts\AIService::class)` true
- [ ] `php artisan tinker --execute="app(App\Contracts\AIService::class)"` resolves
- [ ] Test: `ai_enabled = false` → no provider call
- [ ] Test: `ai_enabled = true` → provider called
