# F1.1 — HR review request queue

## Goal
HR bisa lihat, review, approve/reject request konsultasi dari employee.

## Current State
- Employee submit request via `requestConsultation` → auto-assign consultant
- Tidak ada HR review step — langsung assign
- HR hanya lihat dashboard aggregate

## Perubahan

1. Tambah status `pending_hr_review` di `perusahaan_sessions` (atau gunakan existing `scheduled` + `scheduled_at = null`)

2. Buat `app/Http/Controllers/Perusahaan/HrReviewController.php`:
   - `index` — list pending requests dengan filter
   - `approve` — assign consultant (dari pool), set status `scheduled`
   - `reject` — set status `rejected`, kirim notifikasi ke employee

3. Update `requestConsultation` flow:
   - Employee submit → status `pending_hr_review`
   - HR approve → assign consultant → status `scheduled` (menunggu slot proposal)
   - HR reject → status `rejected` + reason

4. View: `resources/views/perusahaan/hr-review.blade.php`

5. Route:
```php
Route::middleware('role:hr_admin,admin')->group(function () {
    Route::get('/review', [HrReviewController::class, 'index'])->name('review');
    Route::post('/review/{session}/approve', [HrReviewController::class, 'approve'])->name('review.approve');
    Route::post('/review/{session}/reject', [HrReviewController::class, 'reject'])->name('review.reject');
});
```
