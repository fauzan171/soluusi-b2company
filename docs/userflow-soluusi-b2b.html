Ringkasan Sistem

8 Role Efektif

  • superadmin (role name admin) — global, semua + view-as + assign pool
  • klinik_admin — 1 klinik, checkout link, markup
  • associate — pervorma + payout referral
  • hr_admin — agregat, roster, review request
  • employee — WHO-5, booking, chat, rating
  • consultant — jadwal, sesi, proposal, chat CAP
  • bk — 1 sekolah, refer (consent wajib)
  • student — WHO-5, booking, TANPA chat

Uang — Nyata vs Stub

  • ✅ Midtrans Snap + webhook verify · voucher · markup cap · ledger split + reverse · HAP pervorma
  • ⚠️ Settle margin ke klinik = manual admin
  • ❌ Xendit, gateway-level split (SPLIT_ON=false)
  • ❌ Billing B2B: PEPM invoice, subscription sekolah, MHCU flat
